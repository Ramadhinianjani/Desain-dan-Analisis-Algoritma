# Desain dan Analisi Algoritma

---
## Deskripsi Proyek
Proyek ini membahas penyelesaian **0/1 Knapsack Problem** menggunakan pendekatan **Dynamic Programming** dengan studi kasus **perbankan**.  
Tujuan utama dari program ini adalah menentukan kombinasi produk investasi bank yang memberikan **return maksimum** tanpa melebihi **batas dana yang tersedia**.

Setiap produk investasi hanya dapat:
- ✔ Dipilih satu kali  
- ❌ Tidak dapat dipilih sebagian

Sehingga permasalahan ini termasuk ke dalam **0/1 Knapsack Problem**.

---

## Studi Kasus Perbankan
Sebuah bank memiliki keterbatasan dana untuk dialokasikan ke berbagai produk investasi. Bank ingin memilih kombinasi produk yang menghasilkan **keuntungan (return) maksimal** tanpa melampaui **batas dana maksimum**.

---

## Metode yang Digunakan
- **Algoritma** : 0/1 Knapsack
- **Pendekatan** : Dynamic Programming
- **Bahasa Pemrograman** : Python
- **Strategi** :
  - Tabel DP untuk menghitung return maksimum
  - Backtracking untuk menentukan item terpilih
  - State Space Tree untuk visualisasi keputusan
  - Pruning untuk efisiensi pencarian solusi
